# Dataset Description

## Dataset Title

Akulaku Fintech Reviews Dataset

## Description

This dataset consists of user reviews collected from the Akulaku application on Google Play Store.

The dataset was developed to support the research entitled:

"A Semi-Supervised Learning Framework with Active Learning for Fintech Sentiment Classification"

## Dataset Statistics

- Initial Reviews: 55,500
- After Cleaning: 36,131
- Final Dataset: 36,024
- Language: Indonesian
- Domain: Financial Technology (FinTech)

## Sentiment Classes

- Positive
- Neutral
- Negative

## Preprocessing

- Case Folding
- Text Cleaning
- Normalization
- Tokenization
- Stopword Removal
- Stemming
- TF-IDF Vectorization

## Feature Selection

- Chi-Square Feature Selection
- Initial Features: 5,000
- Selected Features: 2,000

## Research Applications

- Sentiment Analysis
- FinTech Analytics
- Active Learning
- Semi-Supervised Learning
- Machine Learning
