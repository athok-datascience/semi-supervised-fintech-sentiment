# A Semi-Supervised Learning Framework with Active Learning for Fintech Sentiment Classification

## Authors

- Achmad Agus Athok Miftachuddin
- Anggun Dwi Cahyaningrum

## Overview

This repository contains the dataset description, source code, preprocessing pipeline, active learning framework, machine learning models, and evaluation results used in the research entitled:

"A Semi-Supervised Learning Framework with Active Learning for Fintech Sentiment Classification"

The study investigates sentiment classification of Akulaku fintech application reviews using a hybrid Semi-Supervised Learning framework integrating Active Learning and Machine Learning techniques.

## Research Contributions

- Lexicon-Based Initial Labeling
- IndoBERT Self-Training
- Active Learning Sample Selection
- TF-IDF Feature Extraction
- Chi-Square Feature Selection
- BorderlineSMOTE
- Class Weight Optimization
- Support Vector Machine (SVM)
- Naïve Bayes Classification

## Dataset Information

- Domain: Financial Technology (FinTech)
- Language: Indonesian
- Source: Google Play Store Reviews
- Initial Reviews: 55,500
- Final Dataset: 36,024 Reviews
